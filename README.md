# 🌦️ Weather App

A simple and responsive **Weather Application** built using **HTML, CSS, and JavaScript** that fetches real-time weather data from a public Weather API. Users can search for any city and get current weather details instantly.

---

## 🚀 Features

- 🌍 Search weather by city name  
- 🌡️ Displays temperature, humidity, and wind speed  
- ☁️ Shows weather condition (Clear, Cloudy, Rain, etc.)  
- 📱 Fully responsive design  
- ⚡ Real-time data using Weather API  
- ❌ Error handling for invalid city names  

---

## 🛠️ Tech Stack

- **HTML** – Structure of the application  
- **CSS** – Styling and responsive design  
- **JavaScript (ES6)** – Logic and API handling  
- **Weather API** – Fetch real-time weather data
